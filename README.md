# Лабораторная работа №2
Сайт о раздельном сборе и переработке мусора. Например, что можно сортировать, куда это отнести и с кем объединиться.

### Структура
```
lab2/
├── index.html       — главная страница с приветствием и навигацией
├── classes.html     — коды переработки: пластик, бумага, металл, стекло
├── points.html      — пункты приёма вторсырья в Самаре (таблица)
├── community.html   — эко-сообщества Самары со ссылками
├── css/style.css    — общий файл стилей для всех страниц
└── img/             — фоновое изображение и картинки кодов переработки
```

# Лабораторная работа №3
---

Каркас проекта взят из [teach-kirshdv/js-tasks](https://github.com/teach-kirshdv/js-tasks)

### Структура:
```text
lab3/
├── package.json       # зависимости и npm-скрипты
├── package-lock.json  # зафиксированные версии зависимостей
└── src/
    ├── core.js        # реализованные функции
    └── core.spec.js   # тесты
```

### Использованные технологии:
- JavaScript — язык программирования.
- Node.js — среда выполнения.
- Mocha — тестовый фреймворк.
- Prettier — автоформатирование кода.

### Реализованные функции:
- `isInteger` - проверка на целое число через побитовое ИЛИ
- `even` - массив чётных чисел от 2 до 20
- `sumTo` - сумма чисел до n циклом
- `recSumTo` - сумма чисел до n рекурсией
- `factorial` - факториал
- `isBinary` - проверка, является ли число степенью двойки
- `fibonacci` - n-е число Фибоначчи
- `getOperationFn` - функция, которая запоминает значение и применяет к нему операцию
- `sequence` - генератор арифметической последовательности
- `deepEqual` - глубокое сравнение объектов рекурсией
