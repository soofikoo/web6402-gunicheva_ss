# Лабораторная работа №3


Каркас проекта взят из [teach-kirshdv/js-tasks](https://github.com/teach-kirshdv/js-tasks)

### Структура:
```text
lab3/
├── package.json       # зависимости и npm-скрипты
├── package-lock.json  # зафиксированные версии зависимостей
└── src/
    ├── core.js        # реализованные функции
    └── core.spec.js   # тесты
```

### Использованные технологии:
- JavaScript — язык программирования.
- Node.js — среда выполнения.
- Mocha — тестовый фреймворк.
- Prettier — автоформатирование кода.

### Реализованные функции:
- `isInteger` - проверка на целое число через побитовое ИЛИ
- `even` - массив чётных чисел от 2 до 20
- `sumTo` - сумма чисел до n циклом
- `recSumTo` - сумма чисел до n рекурсией
- `factorial` - факториал
- `isBinary` - проверка, является ли число степенью двойки
- `fibonacci` - n-е число Фибоначчи
- `getOperationFn` - функция, которая запоминает значение и применяет к нему операцию
- `sequence` - генератор арифметической последовательности
- `deepEqual` - глубокое сравнение объектов рекурсией


# Лабораторная работа №4

Сайт о раздельном сборе отходов из лабораторной работы № 2 доработан с помощью CSS и JavaScript.

### Реализовано

- Flexbox-вёрстка списка материалов на странице «Что сортировать».
- Grid-вёрстка карточек сообществ на странице «С кем сортировать».
- Все цвета вынесены в CSS-переменные.
- CSS-анимация падающих листьев на главной странице с помощью `@keyframes`.
- Форма подписки на новости о событиях с тремя типами полей - `text`, `email` и `checkbox`.
- JavaScript-класс `Subscriber` с конструктором и методом `printInfo()` для форматированного вывода данных в консоль.
- При отправке формы создаётся объект `Subscriber` и вызывается его метод `printInfo()`.
- CSS-классы названы по методологии БЭМ.

### Основные файлы

- `lab4/index.html` - главная страница с анимацией падающих листьев.
- `lab4/classes.html` - категории вторсырья и маркировки переработки.
- `lab4/points.html` - таблица пунктов приёма вторсырья.
- `lab4/community.html` - карточки экологических сообществ и форма подписки.
- `lab4/css/style.css` - стили сайта, CSS-переменные и анимация.
- `lab4/js/subscribe.js` - класс `Subscriber` и обработчик отправки формы.
